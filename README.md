# 🛒 Amazon Clone

An Amazon-inspired e-commerce website developed using HTML, CSS, and JavaScript. This project replicates the basic design and functionality of the Amazon homepage while providing a responsive and user-friendly interface.

---

## 🌟 Overview

The purpose of this project is to enhance front-end development skills by recreating the layout and functionality of a modern e-commerce platform.

The project focuses on creating a responsive design, an attractive user interface, and smooth navigation.

---

## ✨ Features

- Responsive homepage design
- Navigation bar with a search option
- Product categories section
- Product cards with images and descriptions
- Shopping cart icon
- Footer section
- Mobile-friendly layout

---

## 🛠️ Tech Stack

### Frontend

- HTML
- CSS

---

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/adeeba0003-creator/Amazon-Clone.git
```

### Move to the project directory

```bash
cd Amazon-Clone
```

### Run the project

Open the `index.html` file in your browser.
